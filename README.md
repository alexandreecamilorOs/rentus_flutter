# Rentus Flutter

Proyecto Flutter creado en una carpeta aparte (`rentus_flutter`) para replicar las vistas principales del proyecto Android (Compose), sin archivos binarios para evitar errores al crear PR:

- Login
- Registro
- Home
- Properties + Create/Detail/Edit
- About
- Profile
- Notifications
- Contracts
- Payments
- Maintenance
- My Requests
- Requests
- My Reports
- Settings

## Cómo abrirlo

1. Descarga esta carpeta `rentus_flutter`.
2. En Android Studio / Google (Flutter) abre la carpeta como proyecto Flutter.
3. Ejecuta:

```bash
flutter pub get
flutter run
```

## Estructura

- `lib/main.dart`: navegación y rutas.
- `lib/screens/`: pantallas.
- `lib/widgets/`: componentes reutilizables.
